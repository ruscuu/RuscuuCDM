# Ruscuu Cooldown Manager Forever

Addon para **World of Warcraft: Forever** (interfaz 16001) que aplica el estilo visual Ruscuu al Cooldown Manager de Blizzard: iconos cuadrados con borde morado neón, barras moradas y texto con contorno.

Solo cambia la apariencia; no lee datos de combate, así que respeta las restricciones de addons de Forever.

## Instalación

1. Copia la carpeta `RuscuuCDM` en la carpeta `Interface\AddOns` de tu instalación de WoW: Forever.
2. Activa el Cooldown Manager en las opciones de interfaz de Blizzard.
3. Entra al juego y escribe `/ruscuu`.

## Comandos

| Comando | Qué hace |
|---|---|
| `/ruscuu` o `/rcdm` | Abre el panel de opciones |
| `/ruscuu skin` | Reaplica el estilo |
| `/ruscuu debug` | Muestra qué visores de Blizzard se encontraron |
| `/ruscuu reset` | Restaura la configuración por defecto |
